Este é o Certificado Digital. O site que tem como objetivo automatizar o processo de geração de diplomas, otimizando tempo da sua instituição.

Siga os passos abaixo para utilizar o site:
1. Primeiramente, acesse a aba Configurar Dados para acessar todas as opções bases para começar a criação.
2. No botão Baixar Planilha Base, você terá acesso a planilha para ser preenchida com os dados necessários de cada aluno.
3. Por meio do botão Escolher Modelo, você adicionará o modelo desejado para a elaboração dos diplomas.
4. Por fim, depois de unir todas as informações dos estudantes, acesse a aba Home para adicionar a planilha modificada.
